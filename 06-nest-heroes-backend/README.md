# 🛡️ 06 - Nest Heroes Backend

Servidor backend desarrollado con NestJS para proveer servicios a la aplicación de Héroes.

## 🚀 Temas Cubiertos

- **Arquitectura de NestJS**: Módulos, Controladores y Servicios.
- **REST API**: Definición de endpoints CRUD.
- **Tipado con DTOs**: Validación de datos de entrada (Data Transfer Objects).
- **Paginación**: Implementación de lógica de paginado en el servidor.
- **Búsqueda Avanzada**: Búsqueda por parámetros complejos (Advance Search).
- **Entity**: Estructura de datos del dominio.

---

## 🛠️ Cómo ejecutar
1. Instalar dependencias: `npm install`
2. Levantar el servidor: `npm run start:dev`
3. Base de datos: El servidor utiliza datos en memoria (para fines educativos).
