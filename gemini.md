# 🚀 Curso: React de Cero a Experto (Fernando Herrera)

Este documento sirve como bitácora y guía de trabajo para el curso de React (TypeScript) de Fernando Herrera. Aquí registraremos el progreso, notas importantes y configuraciones específicas de cada sección.

## 📁 Estructura del Proyecto

El repositorio está organizado por secciones numeradas, cada una representando un hito en el aprendizaje:

1. `01-reforzamiento`: Repaso de TypeScript y conceptos base.
2. `02-firsts-steps`: Primeros pasos con React y Vite.
3. `03-gifs-app`: Aplicación práctica para búsqueda de GIFs (Fetch API, Hooks básicos).
4. `04-hooks-app`: Profundización en Hooks (useState, useEffect, useMemo, etc.).
5. `05-heroes-app`: Manejo de rutas con React Router y autenticación básica.
6. `06-nest-heroes-backend`: Backend de apoyo para la aplicación de héroes.
7. `07-teslo-shop`: **[ACTUAL]** Aplicación de Ecommerce completa.
