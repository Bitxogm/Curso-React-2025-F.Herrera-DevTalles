# ⚛️ 02 - First Steps in React

Primer contacto con React 19 y TypeScript. Configuración inicial y conceptos base de una aplicación moderna.

## 🚀 Temas Cubiertos

- **JSX / TSX**: Estructura de componentes.
- **Props**: Paso de información entre componentes (obligatorias y opcionales).
- **Default Props**: Valores por defecto y alternativas modernas.
- **Componentes**: Estructura de archivos y organización.
- **Vitest & React Testing Library**: Introducción al testing unitario.
- **Snapshots**: Verificación de renderizado consistente.
- **Helpers**: Separación de lógica de negocio (Math Helpers).

---

## 🛠️ Cómo ejecutar
1. Instalar dependencias: `npm install`
2. Correr proyecto: `npm run dev`
3. Correr tests: `npm test`
