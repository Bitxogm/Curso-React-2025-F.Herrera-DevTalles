# ⚡ 01 - Reforzamiento de TypeScript

Esta sección se centra en asentar las bases sólidas de TypeScript necesarias para dominar React con tipado estricto.

## 🚀 Temas Cubiertos

- **Variables y Tipos**: Uso de `const` y `let`.
- **Template Strings**: Concatenación moderna de strings.
- **Objetos Literales**: Tipado de objetos e interfaces básicas.
- **Arreglos (Arrays)**: Métodos comunes y tipado.
- **Funciones**: Argumentos, valores de retorno y arrow functions.
- **Desestructurización**: Objetos y arreglos de forma eficiente.
- **Importaciones y Exportaciones**: Modularización del código.
- **Promesas**: Manejo de asincronía básica.
- **Fetch API**: Consumo de servicios externos.
- **Async / Await**: Sintaxis moderna para procesos asíncronos.

---

## 🛠️ Cómo ejecutar
1. Instalar dependencias: `npm install`
2. Correr proyecto: `npm run dev`
