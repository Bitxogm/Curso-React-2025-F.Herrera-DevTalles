# 🛍️ 07 - Teslo Shop

Proyecto final: Ecommerce completo desarrollado con las tecnologías más modernas del ecosistema React.

## 🚀 Temas Cubiertos

- **Autenticación**: Registro, Login y persistencia de sesión.
- **Estado Global**: Manejo avanzado de estados complejos con **Zustand**.
- **Data Fetching**: Optimización de peticiones con **TanStack Query** (React Query).
- **Panel Administrativo**: Gestión de productos, inventario y dashboard.
- **Formularios Avanzados**: Validación compleja con React Hook Form.
- **Auth Layouts**: Sistemas de layouts diferenciados para Auth, Shop y Admin.

---

## 🛠️ Cómo ejecutar
1. Instalar dependencias: `npm install`
2. Correr proyecto: `npm run dev`
