Este repositorio contiene todos los proyectos y ejercicios realizados durante el curso de **React (TypeScript)** impartido por **Fernando Herrera** en [DevTalles](https://devtalles.com/).

## ⚙️ Cómo ejecutar los proyectos

Cada carpeta de proyecto es independiente. Para ejecutar cualquiera de ellos:

1. Entra en la carpeta deseada:
   ```bash
   cd 0X-nombre-del-proyecto
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
