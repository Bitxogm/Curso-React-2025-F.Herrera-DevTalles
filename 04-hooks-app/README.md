# 🪝 04 - Hooks App

Laboratorio completo para dominar todos los Hooks integrados en React, incluyendo las novedades de React 19.

## 🚀 Temas Cubiertos

- **Hooks Básicos**: `useState`, `useEffect`, `useRef`.
- **Manejo de Estado Complejo**: `useReducer` para lógica estructurada.
- **Optimización**: `useMemo`, `useCallback` y `React.memo`.
- **Novedades React 19**: `useOptimistic`, `use` (Suspense), `useTransition`.
- **Custom Hooks**: Patrones de reutilización avanzados.
- **Context API**: Manejo de estado global ligero con `useContext`.
- **Router Básico**: Estructura de navegación simplificada.

---

## 🛠️ Cómo ejecutar
1. Instalar dependencias: `npm install`
2. Correr proyecto: `npm run dev`
